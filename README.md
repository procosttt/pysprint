# PySprint

Мобильный тренажёр коротких задач по Python. Этап 3: разминка и авторские прототипы заданий №2, №5 и №8 ЕГЭ, свободный запуск кода через Pyodide в Web Worker, без проверки решений.

## Что умеет сейчас

- Список из десяти задач: три короткие разминки и семь авторских прототипов ЕГЭ
- Условие открывается поверх редактора в диалоге; в рабочем режиме виден большой `textarea`-редактор
- Одна лента Python-клавиш, Undo/Redo в шапке редактора и черновики в `localStorage`
- Кнопка **▶ Запустить код** выполняет ровно код из редактора, как Run Module в IDLE
- Вывод `print()` и ошибки Python показываются в панели **ВЫВОД** после запуска
- Python загружается из npm-пакета `pyodide@314.0.6`, runtime — с CDN `https://cdn.jsdelivr.net/pyodide/v314.0.6/full/`
- Тайм-аут 3 секунды и кнопка **Остановить** завершают Worker и создают новый
- Код ограничен 50 000 символами, каждый из потоков `stdout` и `stderr` — 50 000 символами во время записи

## Безопасность запуска

- Worker и тайм-аут защищают интерфейс от обычных бесконечных циклов
- Лимит вывода уменьшает риск переполнения памяти через `print()`
- Браузер не предоставляет надёжный жёсткий лимит памяти для отдельного Worker
- Специально написанный код с огромным выделением памяти всё ещё может привести к закрытию вкладки браузером
- Pyodide не является полноценной песочницей
- Приложение предназначено только для запуска собственного кода пользователя

## Требования

- Node.js 20 или новее
- npm

## Установка

```text
npm install
```

## Запуск (разработка)

```text
npm run dev
```

Откройте локальный URL из вывода Vite, обычно `http://localhost:5173`. Первая загрузка Python требует сеть; дальше помогает обычный HTTP-кэш браузера. Полный офлайн-режим будет на этапе 4.
