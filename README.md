# PySprint

Мобильный тренажёр коротких задач по Python. Этап 1: список задач, экран условия, редактор на `textarea`, панель быстрых Python-клавиш и черновики в `localStorage`. Запуск кода и проверка решений пока не подключены.

## Требования

- Node.js 20 или новее
- npm

## Установка

```text
npm install
```

## Запуск (разработка)

```text
npm run dev
```

Откройте локальный URL из вывода Vite, обычно `http://localhost:5173`.

## Тесты

```text
npm run test -- --run
```

Режим наблюдения:

```text
npm run test
```

## Проверка типов

```text
npm run typecheck
```

## Lint

```text
npm run lint
```

## Production-сборка

```text
npm run build
```

Просмотр собранного приложения:

```text
npm run preview
```
